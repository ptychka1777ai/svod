# Свод — задачи, идеи и материалы

Личный таск-менеджер: канбан-доска, календарь, список, библиотека материалов,
проекты, приоритеты и дедлайны.

**Сайт:** https://ptychka1777ai.github.io/svod/

---

## Как это устроено

```
GitHub-репозиторий (svod)
 └─ index.html — всё приложение в одном файле
GitHub Pages — бесплатный хостинг
 └─ обновляется автоматически при каждом git push
```

- Сервера и базы данных нет — данные хранятся **в браузере** (localStorage)
  на том устройстве, где вы работаете.
- На сайте лежит только код приложения — ваши задачи туда не попадают
  и никому не видны.

## Перенос данных между устройствами

1. На старом устройстве: **Экспорт** (в боковой панели) → скачается JSON-файл.
2. Переслать файл себе (почта, мессенджер, диск).
3. На новом устройстве: **Импорт** → выбрать этот файл.

Тот же способ — регулярный бэкап.

## Как обновить приложение

```
cd "~/Desktop/Task Iuliia/svod-app"
git add .
git commit -m "описание изменений"
git push
```

Через 1–2 минуты изменения появятся на сайте.
