# Свод — задачи, идеи и материалы

Личный таск-менеджер: канбан-доска, календарь, список, библиотека
материалов, проекты, приоритеты, дедлайны — плюс Telegram-бот,
который создаёт задачи из текста, голосовых и фото.

**Как развернуть:** см. [README_RENDER.md](README_RENDER.md)

---

## Состав

```
server.js          — сервер: API + Telegram-бот (Node.js + Express)
public/index.html  — веб-приложение (один файл)
render.yaml        — чертёж сервиса для Render (web + диск)
index.html         — СТАРАЯ автономная версия (GitHub Pages, данные в браузере)
```

## Данные и их сохранность

- Хранятся на сервере: `/data/svod.json` (Persistent Disk на Render) —
  одинаковые на всех устройствах.
- **Автокопии**: при изменениях (не чаще раза в час) база копируется
  в `/data/backups` (хранится 30 дней); раз в день бот присылает файл
  базы в Telegram — копия живёт вне Render. Список копий и скачивание —
  во вкладке «Корзина».
- **Корзина**: удаление — мягкое, запись 30 дней можно восстановить
  (плашка «Отменить» или вкладка «Корзина»), потом стирается насовсем.
- **Импорт со страховкой**: перед импортом делается снимок, есть
  «Отменить импорт»; повреждённый файл базы не перезаписывается —
  сервер сам поднимается из последней исправной копии.
- **Календарь**: кнопка «Календарь» в боковой панели даёт секретную
  ICS-ссылку — задачи со сроками появляются в календаре iPhone /
  Google Calendar (события с точным временем — в свой час).
- Вход в приложение по паролю (`APP_PASSWORD`), попытки перебора
  ограничены; фото раздаются по отдельному токену, пароль в URL
  не попадает.
- Бот отвечает только владельцу (`TELEGRAM_CHAT_ID`).
- Ручной бэкап: кнопки «Экспорт» / «Импорт» в боковой панели.

## Telegram-бот умеет

- **Текст** — «завтра в 15:00 позвонить в лабораторию, срочно» → задача
  со сроком, временем и приоритетом (разбор через GPT); если указано
  время — в назначенный час бот пришлёт напоминание.
- **Голосовое** — распознаётся (Whisper) → задача.
- **Фото** — записка/скриншот/афиша → понимает содержимое (GPT-4o-mini
  vision), сохраняет фото и создаёт запись.
- **Ссылка** — сохраняется как материал в библиотеку.
- `/menu` — панель управления: сегодня, активные, идеи,
  библиотека, проекты, сводка (кнопки в чате).
- Каждое утро (8:00, меняется переменной `DIGEST_HOUR`) бот сам
  присылает план на день: задачи на сегодня и просроченные.
- `/list` — активные задачи, `/help` — подсказка.
