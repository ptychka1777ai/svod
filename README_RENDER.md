# 🚀 Деплой «Свода» на Render

Полноценный таск-менеджер: веб-приложение + общая база + Telegram-бот
(текст, голосовые, фото). Данные хранятся на сервере — одинаковые
на телефоне и компьютере.

---

## Архитектура

```
Render Web Service «svod» (план Starter, ~$7/мес)
 ├─ server.js — API + веб-приложение + Telegram-бот (webhook)
 ├─ Persistent Disk /data → svod.json + фото (переживает деплои)
 └─ вход в приложение по паролю (APP_PASSWORD)
Секреты → Environment Variables в дашборде Render
```

---

## Шаг 1. Создать Telegram-бота (2 минуты)

1. В Telegram откройте **@BotFather** → команда `/newbot`
2. Имя: например `Свод` · юзернейм: например `svod_iuliia_bot`
3. BotFather пришлёт **токен** вида `1234567:AA...` — скопируйте его.

⚠️ Токен никому не пересылайте (в том числе в чаты) — его нужно
вставить только в Render на шаге 3.

## Шаг 2. Создать сервис на Render

1. https://dashboard.render.com → **New +** → **Blueprint**
2. Выберите GitHub-репозиторий **ptychka1777ai/svod**
3. Render прочитает `render.yaml` → согласитесь создать сервис
   `svod` (web + диск 1 ГБ)

## Шаг 3. Вписать секреты

В сервисе → вкладка **Environment** → заполните переменные:

| Переменная | Что вписать |
|---|---|
| `APP_PASSWORD` | придумайте пароль для входа в приложение |
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 (от BotFather) |
| `OPENAI_API_KEY` | на вашем Mac: файл `~/Desktop/Project1/.env`, строка `OPENAI_API_KEY=` — скопируйте значение (нужен для голосовых и фото) |
| `TELEGRAM_CHAT_ID` | уже заполнено (439079989) — ваш chat id из дентарт-бота |
| `DIGEST_HOUR` | необязательно: час утренней сводки по Киеву (по умолчанию 8) |
| `CALENDAR_ICS_URL` | необязательно: секретный iCal-адрес рабочего календаря (Google: настройки календаря → «Секретный адрес в формате iCal») — встречи появятся в календаре «Свода» и в утренней сводке |

## Шаг 4. Дождаться деплоя

В логах появится:
```
🗂 Свод запущен на порту 10000 (вход по паролю)
Telegram webhook: {"ok":true,...}
```

Готово:
- **Сайт** — адрес вида `https://svod-XXXX.onrender.com` (виден вверху
  страницы сервиса). Откройте → введите ваш `APP_PASSWORD`.
- **Бот** — напишите ему в Telegram что угодно: текст, голосовое, фото.

---

## Как это живёт дальше

- Бот подключает webhook сам при каждом запуске — ничего настраивать не надо.
- Задача из Telegram появляется на сайте автоматически (обновление раз в 20 сек).
- Обновление кода: `git push` → Render передеплоит сам.
- Бэкап: кнопка «Экспорт» в приложении (скачивает JSON), «Импорт» — восстановление.
